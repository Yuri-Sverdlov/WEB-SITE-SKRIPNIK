## 2. Фронт — профиль и формы

### API (`src/api/readerProfile.ts` или аналог)

- `fetchMyProfile()` — своя строка или null.
- `createProfile(displayName)` — INSERT; ошибки: занято, запрещено, RLS — **русские** тексты («Это имя уже занято…» и т.д.).

### UI (общий поток для StoryDetail + GuestBook)

- **Нет профиля:** вместо поля «Имя» в `ReaderMessageForm` (или обёртка) — экран выбора имени + пояснение «изменить потом нельзя»; после успеха — обычная форма только с текстом.
- **Есть профиль:** над формой «Вы пишете как: **&lt;имя&gt;**»; поля «Имя» нет; insert **без** подмены имени с клиента (триггер всё равно перезапишет).
- **Автор** (`is_admin`) — без профиля читателя: комментарии/ответы как сейчас (не ломать TASK-016).

### Админка (TASK-015 страницы)

- В **`AdminComments`**, **`AdminGuestbook`**, **`AdminBanned`**: рядом с `author_name` / `last_name` показывать **email** (batch RPC по `user_id` видимых строк или одним запросом списка — на усмотрение, без N+1 на каждую строку без нужды).
