# Блок D — комментарии и гостевая книга (план архитектора)

> Источник: бриф консультанта, 2026-10-02. **Активное задание кодеру — только `tasks/TASK.md`.**

## Правила блока

| Кто | Действие |
|---|---|
| **Кодер** | Один TASK за раз → `tasks/REPORT.md` → без push до указания в TASK |
| **Пользователь** | Выполняет SQL в Supabase SQL Editor; вставляет вывод в REPORT |
| **Архитектор** | Приёмка (build, lint, ревью, браузер); commit + **push после подтверждения пользователя** (см. `AGENTS.md` § Push на GitHub) |
| **Консультант** | Один отчёт в конце блока (см. низ) |

**Не входит в блок:** ответы автора, модерация/удаление, редактирование своих сообщений (этапы 8–9).
