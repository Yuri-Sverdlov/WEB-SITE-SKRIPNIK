## Что сделать

### 1. Layout

- **`src/components/SiteHeader.tsx`** — шапка в стиле F1 (`paper`, `ink`, `accent`, `font-ui`).
- **`src/components/SiteFooter.tsx`** — подвал.
- **`src/components/SiteLayout.tsx`** — обёртка: header + `<main>{children}</main>` + footer.
- **`App.tsx`:** убрать старый `<nav>` (Home, StoriesNew, …). Обернуть `<Routes>` в `SiteLayout` **или** вложить layout через route — без дублирования header на `/admin` (админка может **без** публичной шапки или с минимальной полосой «← на сайт» — на усмотрение, главное не ломать `/admin`).

### 2. StoryDetail

- Убрать **`SiteHeaderPreview`** (логика в общем layout).
- Убрать **`StoriesTabNav`** со страницы **одного рассказа** (вкладки только на списках).
- Сохранить стили F1 для текста рассказа.

### 3. Document title

- **`react-helmet-async`** или лёгкий **`useDocumentTitle`** hook — без тяжёлых зависимостей по возможности.
- `StoryDetail`: title = `` `${story.title} — ${AUTHOR_NAME}` `` (константы из `site.ts`).

### 4. Favicon

- `public/favicon.svg` (или `.ico`) — нейтральная буква/книга, цвета `ink`/`accent`.
- Подключить в `index.html`.

### 5. Русификация видимых строк

- `Home`, `Contact`, `GuestBook`, auth-страницы, списки — заменить английские заголовки/плейсхолдеры на русский (кабинет — **F5**, но «Stories» в публичном nav уже не должно остаться).

### 6. Скриншот (опционально)

- Расширить `scripts/screens.mjs` или вручную: один кадр **главной** с новым меню — в REPORT путь, если сделали.
