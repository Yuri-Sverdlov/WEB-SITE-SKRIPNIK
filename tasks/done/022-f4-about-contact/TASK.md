## Что сделать

### 1. `src/config/site.ts`

- Добавить **`CONTACT_INTRO`** — перенести сюда фразу со страницы «Связь» (или улучшить по смыслу брифа: коротко, без формы).
- При необходимости **`AUTHOR_PHOTO_ALT`** для заглушки.

### 2. `src/pages/Home.tsx` — «Об авторе»

- Заголовок **h1:** «Об авторе» или имя из `AUTHOR_NAME` — согласованно с меню.
- **Заглушка фото:** квадрат **1:1**, аккуратная рамка/фон (`border-light`), подпись вроде «Фото будет добавлено» (константа или короткая строка в `site.ts`).
- Блок **`BIOGRAPHY`** — типографика читабельная (`font-story`, ~18px, `max-w-2xl`).
- Секция **«Последние рассказы»:** запрос к Supabase (существующий API списка — `fetchStoriesNew(0)` или отдельный limit 5 по `published_at`); для каждого — **ссылка** на `/stories/:id`, заголовок, дата (`published_at`, ru-RU).
- Если рассказов 0 — нейтральная фраза «Пока нет опубликованных рассказов».
- Ссылка **«Все рассказы»** внизу секции.

### 3. `src/pages/Contact.tsx`

- Текст из **`CONTACT_INTRO`** + **`mailto:`** на **`CONTACT_EMAIL`** (как сейчас, без дублирования строк в JSX).

### 4. Скриншот (желательно)

- `npm run screens` с **`SHOTS=home,contact`** (расширить `scripts/screens.mjs` при необходимости) → `reference/screens/f4-home.png`, `f4-contact.png` (1280).
